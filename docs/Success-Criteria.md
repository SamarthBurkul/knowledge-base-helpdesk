# Success Criteria

| Area | Success Condition |
|---|---|
| Authentication | User can log in successfully |
| Authorization | Users can access only permitted functions |
| Knowledge Base | Articles can be created, viewed, updated and deleted |
| Search | Users can find relevant articles |
| Testing | Automated tests execute successfully |
| CI | Jenkins automatically builds the project |
| Selenium | Critical user journeys execute successfully |
| Docker | Application runs successfully in a container |
| Deployment | Docker image can be deployed successfully |
| Ansible | Target environment can be provisioned automatically |
| Reliability | Health check confirms application availability |
| Recovery | Previous stable release can be restored |
| Idempotency | Re-running Ansible does not make unnecessary changes |
