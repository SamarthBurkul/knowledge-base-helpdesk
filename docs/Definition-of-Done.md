# Knowledge Base Helpdesk - Definition of Done

A task or user story is considered Done only when all applicable conditions
below are satisfied.

## Development

- Required functionality is implemented.
- Code follows the project structure and coding standards.
- No known critical defect remains.

## Testing

- Appropriate unit tests are implemented.
- Relevant tests pass successfully.
- Selenium tests are added for applicable critical user journeys.
- Regression issues are checked.

## Git and Collaboration

- Code is committed with a meaningful commit message.
- Code is pushed to the appropriate feature branch.
- Pull Request is created.
- Pull Request review is completed.
- Approved changes are merged into the development branch.

## CI/CD

- Jenkins pipeline executes successfully.
- Maven build completes successfully.
- Automated tests pass.
- Docker image is built successfully when applicable.
- Deployment succeeds when applicable.

## Documentation

- Required documentation is updated.
- Configuration or deployment changes are documented.
- Evidence required for the task is archived.

## Final Condition

The feature is considered complete only when it works as expected,
passes applicable tests, is integrated into the project workflow,
and has the required documentation and evidence.
